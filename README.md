# Spilastokkurinn

Leikur í stíl Jet Lag: The Game. 20 spil liggja á grúfu (stokkuð í hvert sinn sem byrjað er upp á nýtt). Smellt er á spil og þraut opnast; sé hún leyst rétt snýst spilið við. Spilið er **bölvun**, **verkefni** eða **spurning**; verkefni og spurningar gefa 1–3 stig þegar þau eru merkt lokið. Staðan vistast í vafranum.

Vefurinn er hreinn HTML/CSS/JavaScript og þarf hvorki netþjón né nettengingu. Opnaðu `index.html` í vafra, eða hýstu möppuna, til dæmis á GitHub Pages.

## Skrár

- `index.html`: síðan
- `js/spil-gogn.js`: spilin 20 og þrautirnar (sem stendur sýnidæmi); `raudt: true` gefur spili rauða bakhlið
- `js/spil.js`: viðmótið; nýjar tegundir þrauta eru skráðar í `SPIL_THRAUTIR`
- `css/spil.css`: útlit
